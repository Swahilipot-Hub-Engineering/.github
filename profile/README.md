## About Us

Swahilipot Hub Foundation has spent almost a decade empowering East African youth
through technology, arts, and entrepreneurship from its home in Mombasa, Kenya.
This organization is home to the engineering team that designs, builds, and
maintains the software behind that mission — from the mobile apps our members use,
to the internal tools that keep our programs running smoothly.

## What We Build

| Area | Description |
|---|---|
| Mobile Apps | Apps that connect youth to Hub programs and opportunities |
| Web Platforms | Public sites and web apps for Hub programs and partners |
| Data & Analytics | Dashboards and visualizations that track program impact |
| Internal Tools | Tooling that supports Hub staff and program operations |
